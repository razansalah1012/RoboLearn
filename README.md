
# RoboLearn — Robotics Learning Platform

RoboLearn is an academic application project focused on supporting robotics learning and club-related activities through a digital platform.

The project aims to provide an accessible and organized environment for users interested in robotics education.

## Project Objectives

- Support robotics learning activities
- Provide a digital environment for educational content
- Improve access to robotics-related resources
- Explore mobile application development for educational use
- Support collaboration during application development

## Technology Stack

The following technologies are associated with the project based on its project description:

| Category | Technologies |
|---|---|
| Framework | Flutter |
| Programming Language | Dart |
| Backend Services | Firebase |
| Database | Cloud Firestore |
| Version Control | Git, GitHub |


## Development Workflow

The repository documentation references the use of sprint-based branches during collaborative development.

This workflow can support:

- Organizing development tasks
- Separating feature implementation
- Managing contributions
- Reviewing changes before integration
- Tracking development progress

## Getting Started

Clone the repository:

```bash
git clone https://github.com/razansalah1012/RoboLearn.git
```

Review the available branches to locate the application source code.

If the Flutter project files are available, install dependencies with:

```bash
flutter pub get
```

Then configure the required Firebase services and run the application:

```bash
flutter run
```
